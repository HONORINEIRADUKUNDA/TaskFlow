# TaskFlow Dashboard

A dynamic, single-page project management dashboard built to demonstrate advanced DOM manipulation, event delegation, and state management using vanilla JavaScript.

## 🚀 Features

* **Task Management:** Create new tasks and dynamically inject them into the board.
* **Column Organization:** Easily move tasks between "To Do", "In Progress", and "Done" states using a dropdown selector.
* **Inline Editing:** Click any task title to edit it directly on the card (`contenteditable`).
* **Real-Time Search:** Filter through tasks instantly using the global search bar.
* **Theme Engine:** Toggle between Light and Dark modes instantly (powered by CSS variables).
* **Efficient Logic:** Utilizes event delegation for all dynamic controls (moving and deleting tasks) to ensure optimal performance.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and accessible forms.
* **CSS3:** Flexbox layout, responsive design, and CSS Custom Properties (variables) for theme toggling.
* **Vanilla JavaScript:** * Element creation and traversal (`document.createElement`, `querySelector`)
  * Advanced Event Handling and Delegation (`e.target.matches`, `.closest()`)
  * Dynamic styling and class manipulation

## 📥 How to Run

This project requires no build tools or package managers. 

1. Clone or download the repository.
2. Open the project folder.
3. Double-click `index.html` to open it in any modern web browser.

## 📁 Project Structure

* `index.html` - The structural markup and UI layout.
* `style.css` - The design system, including dark mode overrides.
